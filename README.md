# Gymnasieskola

## About the project
It is often said that in modern .NET development, you rarely need to write your own SQL, since databases are now typically created using Code First. 
At the same time, it is valuable to understand how databases are structured and how SQL actually works in practice. This project is therefore built using Database First.
I created the database manually by writing SQL code to define tables and relationships, while also practicing more advanced queries using joins. 
This gave me a deeper understanding of how data is connected behind the scenes.
Using scaffolding in Entity Framework, I then generated the models for the console application. Within the application itself, I implemented several methods to filter, search, and present information based on the user’s needs.
